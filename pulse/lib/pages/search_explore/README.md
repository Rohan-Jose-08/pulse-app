# Search / Explore Page (Mocked)

This module provides a Riverpod-based search/explore experience with:

- Rounded search bar with live suggestions
- "Explore Pulses" masonry grid (2-column) with infinite scroll
- Search results view: users (list) and pulses (card rows)

Files:
- `search_explore_providers.dart`: mock data, state providers, pagination
- `search_explore_page.dart`: UI widgets & layouts

Usage:
- Push `SearchExplorePage` via your router, or set as a tab
